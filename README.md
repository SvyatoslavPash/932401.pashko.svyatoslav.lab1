# Персональная страница предпринимателя — Пашко Святослав

Одностраничный сайт-визитка, представляющий профиль предпринимателя и стартапера. Страница выполнена в оранжево-белой цветовой гамме, символизирующей энергию и инновации.

## 📋 Описание

Страница содержит:

- **Шапку** с именем и заголовком  
- **Основной контент** с секциями «Навыки» и «Проекты»  
- **Боковую панель** (`<aside>`) с ключевыми ценностями подхода к бизнесу  
- **Фотографию** автора  
- **Форму обратной связи** (поля: имя, email, сообщение)  
- **Подвал** с копирайтом и годом  

## 🚀 Запуск

Для просмотра страницы достаточно открыть файл `index.html` в любом современном браузере.
